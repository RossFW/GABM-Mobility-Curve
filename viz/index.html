LLM Sensitivity of Generative Agents

Evidence from an Epidemic Model
Industrial & Systems Engineering · Virginia Tech

Generative agent-based modeling lets researchers replace hand-coded behavioral rules with decisions made by a large language model. This study probes 21 LLM configurations from OpenAI, Anthropic, and Google — 420,000 stay-home decisions during a simulated epidemic — to ask whether the LLM behind a generative agent materially shapes the simulation's outcomes.
